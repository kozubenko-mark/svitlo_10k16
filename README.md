# Світло 10к16 — Android-застосунок

Читає публічний канал `t.me/svitlo_10k16` (без Telegram і без підписки). Екран зверху вниз:
1. **Статус** — «Світло є / Світла немає» за закріпленим постом і підпис за графіком (до коли світло,
   наступне відключення, екстрені відключення, «графік на завтра ще не сформований»).
2. **Графік** на сьогодні (ліворуч) і завтра (праворуч) двома стовпчиками; поточне відключення підсвічено.
3. **Чат** з повідомленнями каналу (нижня частина екрана, прокручується окремо), нові повідомлення внизу, як у месенджері; старіші довантажуються кнопкою на початку.
Кнопки «оновити» й ⚙ — у правому верхньому куті картки статусу.

Кнопка ⚙ вгорі відкриває налаштування: тема (як у системі / світла / темна), push-сповіщення
(увімк./вимк.), дозвіл на роботу у фоні. Вночі (будні 23:00–07:00, якщо ранок вихідний — 23:00–09:00)
сповіщення приходять без звуку.

Два віджети: малий 2×2 (статус) і широкий 4×2 (статус + графік на сьогодні й завтра), на обох кнопка «оновити».

Усі налаштування — у `app/src/main/java/com/svitlo/app/Cfg.java`
(канал, номер закріпленого поста, група Yasno).

## Як отримати APK (без Android Studio)

1. Зареєструйтесь на https://github.com (безкоштовно) і створіть новий репозиторій
   (кнопка «New repository», назва довільна, можна Private).
2. Завантажте в нього **весь вміст цієї папки** (кнопка «Add file → Upload files», перетягніть файли й папки).
   Обов'язково має бути папка `.github/workflows/build.yml`. Якщо браузер не завантажив приховану
   папку `.github`, створіть файл вручну: «Add file → Create new file», у назві введіть
   `.github/workflows/build.yml` і вставте вміст файлу.
3. Відкрийте вкладку **Actions**. Збірка стартує сама після завантаження (або натисніть
   «Build APK → Run workflow»). Триває 3–6 хвилин.
4. Коли збірка зелена, відкрийте її й унизу в розділі **Artifacts** скачайте `svitlo-apk`.
   Розпакуйте архів — всередині `app-debug.apk`.
5. Передайте APK на телефон, відкрийте його й дозвольте встановлення з цього джерела.
6. Якщо збірка червона — відкрийте її, скопіюйте текст помилки й надішліть мені.

## Після встановлення

- Відкрийте застосунок, дозвольте сповіщення.
- Натисніть «Налаштувати роботу у фоні» і дозвольте роботу без обмежень батареї
  (на Samsung: Налаштування → Додатки → Світло 10к16 → Батарея → «Без обмежень»), інакше система
  зупинятиме фонову перевірку.
- Додайте віджет: утримуйте головний екран → Віджети → «Світло 10к16».
